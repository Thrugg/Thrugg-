# Hike wish list

Missing a hike? Add one line under **Waiting** and press **Commit changes**. In the app, *Ask for a hike* writes the line for you.

The weekly update (every Monday morning) adds the waiting hikes first, then moves each line to **Done** with the name it was given in the app. If a hike can't be added (outside the four regions, a closed trail, already in the app under another name), the line moves to **Done** with the reason.

Format: `- [ ] what, where — anything specific (asked on date)`
